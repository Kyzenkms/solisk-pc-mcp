Edition / Headless 1.0.0

The server build. No window.

Same protocol, same auth, same audit log as the desktop app — packaged as a CLI for VPS and homelab boxes. Off-Windows, Windows-only tools stay off and 45 portable tools stay on (plus a POSIX shell_exec shim = 46 total); on Windows the CLI serves the full native set, exactly like the GUI.

Install

npm install -g solisk          # Node 22.5+ — macOS, Linux, Windows
npx solisk --mode=stdio        # or run without installing

For a shared instance on a server, use the VPS installer:

ssh root@YOUR_VPS
bash -c "$(curl -fsSL https://raw.githubusercontent.com/Kyzenkms/solisk-pc-mcp/main/self-hosted-setup/vps/install.sh)"
# pick Docker or PM2 when asked — prints the room + key ONCE
The server binds 127.0.0.1 by default. Reach it over SSH tunnel, Tailscale, or a TLS reverse proxy — never publish the node port directly.

Run modes

solisk --mode=http --host 127.0.0.1 --port 3000
solisk --mode=stdio            # Claude Desktop / Cursor / Cline
solisk --status                # probe a running server (exit 0 = up)
solisk --list-tools            # active vs disabled matrix
solisk --setup                 # regenerate config + key

Approval defaults to always: read-only shell commands run, mutating ones are refused. Pass --approval-mode=turbo only when any authenticated client may shell the box.

Local dashboard

Every headless server serves a read-only runtime console at /dashboard (Bearer key, same as MCP): live status, tool inventory with scopes, session count, and the audit-log tail refreshing every 5 seconds. No build step, no external assets — works offline. 

open http://127.0.0.1:3000/dashboard
# paste the owner API key once (kept in tab session storage)

Tailscale remote access

Tailnet-only (recommended):

solisk --mode=http --tailscale
# → https://<machine>.<tailnet>  (dashboard + MCP, tailnet HTTPS)

Public internet (deliberate only):

solisk --mode=http --tailscale-funnel
# Bearer key becomes the entire boundary. Prefer tailnet.

Cloudflare tunnel

A direct pipe from the internet to this box, run by the Cloudflare connector. Two flavors:

Quick — random address, no account:

solisk tunnel quick   # or flip it in the app: Overview → Cloudflare tunnel

Custom domain — stable address on your domain. Needs a Cloudflare account holding that domain. The app (or CLI) walks you through it: browser login (you click once), tunnel creation, DNS routing, token stored as a secret:

solisk tunnel login
solisk tunnel create [name]
solisk tunnel route mcp.yourdomain.com
solisk tunnel custom
Quick addresses change every restart; custom domains don't. The token never prints — tunnel forget drops it.

GUI remote access

The desktop app serves the same console locally and shows every remote path (relay, Cloudflare tunnel, tailnet) under Overview → Endpoints, with a full status breakdown on the Setup tab. 

tailscale serve http://127.0.0.1:3000
# phone on the tailnet → https://<pc>.<tailnet>/dashboard

The console observes only. Approvals and control stay on the PC, exactly as before.

Operator commands

One runtime per machine: commands attach to the running server — GUI or CLI — instead of starting a second one. Output is colored on a terminal, raw when piped. 

solisk dashboard            # probe + print console URL (+ open it)
solisk dashboard --no-open  # print only, for SSH sessions
solisk doctor               # 11 checks: node, config, key, port, tools…
solisk doctor --lint        # exit 2 on any failing check (CI gate)
solisk doctor --json        # machine-readable report on stdout
solisk config get port      # read a value (secrets never print)
solisk config set port 3421 # validated write, bad values rejected
solisk config validate      # schema check without changing anything
solisk rotate-key           # new owner key, old stays valid for handover
solisk logs --lines 50      # audit tail (capped, 500 chars/line)
solisk logs --follow        # stream new audit lines
solisk backup               # timestamped config copy next to config
solisk gui status           # is the desktop app installed? runtime up?
solisk gui setup --installer "C:\path\to\PC Control MCP Setup 1.0.0.exe"
solisk setup                # step-by-step onboarding (needs a terminal)
solisk keys list            # fingerprints only — full keys never print
solisk keys add phone       # read-only by default, prints once
solisk keys add admin --scopes mcp:resources,mcp:tools
solisk keys revoke phone    # by id, label, or key prefix (8+ chars)
solisk relay status         # live relay state (not just config intent)
solisk relay retry          # redial now, same box or remote runtime
solisk tunnel [status]      # cloudflared: installed? logged in? live URL?
solisk tunnel off|quick|custom
solisk tunnel login         # browser login, app waits for the certificate
solisk tunnel create [name] # named tunnel (reused if it exists)
solisk tunnel route <host>  # DNS + token, stored secret, never shown
solisk tunnel forget        # drop token, back to quick
solisk tailscale [status] | serve | funnel --yes | off
config set refuses secrets and unknown keys — use rotate-key for keys. In the running app, dashboard_enabled and tunnel mode apply live; ports and paths apply on restart.

Headless servers dial the hosted relay outbound, same as the GUI — set name + relay_domain and the box appears on the relay. Inbound exposure stays your choice (Tailscale, SSH tunnel, reverse proxy). Opt out with --no-relay or config set relay_enabled false.

Tool matrix

Active on headless: filesystem (20), memory (6), utility (6), network (3), git (10), plus shell_exec (POSIX). Disabled as windows-only: shell, system, system_advanced, input, notification, network_advanced, server. Full audit in pc-control-headless/AUDIT.md.
