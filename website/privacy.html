Privacy policy

What the desktop app keeps locally, what the hosted beta relay processes, and what we intentionally do not collect.

This policy describes the current public beta. No Google account system or hosted account dashboard is currently active.

1. Scope

This policy applies to the PC Control MCP desktop application, project website, and managed relay at mcp.solisk.org. Self-hosted operators control their own relay data and should publish policies appropriate to their deployment.

2. Data stored locally

The desktop application stores configuration on your computer, including device identity, relay settings, permission mode, allowed and denied paths, owner credentials, OAuth configuration, and locally managed scoped-key metadata.

Local configuration is typically stored under %APPDATA%\pc-control-mcp-desktop. You are responsible for protecting your Windows account and local files.

3. Hosted relay data

The managed relay may process device room identifiers, connection status, request metadata, session identifiers, credential hashes, OAuth records, IP addresses needed for security and rate limiting, and operational logs needed to diagnose abuse or outages.

API keys are intended to be stored as salted hashes by the relay. Plaintext credentials are transmitted when registering or authenticating and should only travel over HTTPS/TLS.

4. Tool content

MCP requests and responses can contain file paths, commands, text, screenshots, clipboard data, or other sensitive computer content depending on the tool you invoke. The relay transports requests between your AI client and desktop runtime.

We do not claim ownership of your content. Do not expose information you are not authorized to process, and use local mode or self-hosting when managed relay processing is unsuitable.

5. Website data

The static website does not currently provide user accounts, advertising, or behavioral tracking. Infrastructure providers may retain standard HTTP logs such as IP address, timestamp, user agent, and requested path.

6. Sharing and providers

Data may be processed by infrastructure providers used for DNS, TLS, hosting, and network delivery. We may disclose information when required by law, to investigate abuse, or to protect users and infrastructure.

We do not sell personal information.

7. Retention and deletion

Local data remains until you remove it. Hosted room and token records can be removed by revoking keys, regenerating the MCP URL, or contacting us. Operational logs may be retained for a limited period needed for security and reliability.

For deletion requests, email kyzenkms@duck.com with enough information to identify the relevant hosted device without sending secret keys.

8. Security

No system is risk-free. Use minimum scopes, restrict file paths, keep approval mode enabled for sensitive operations, and rotate any credential that may have been exposed. See the security page for current boundaries.

9. Children

PC Control MCP is a technical computer-control tool and is not directed to children under 13.

10. Changes

We may update this policy as hosted features change. Material changes will update the effective date and should be reviewed before continued hosted-relay use.

11. Contact

Privacy questions: kyzenkms@duck.com.
