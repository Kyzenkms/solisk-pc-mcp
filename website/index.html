Request path

What happens after you connect.

No hidden desktop session. The client speaks MCP, policy decides, Windows returns a structured result.

Connect a client
1

Configure

Add the endpoint and bearer key to Claude, ChatGPT, Cursor, or any MCP client.

"url": "https://mcp.solisk.org/mcp/workspace-id"
2

Discover

The client opens an MCP session and lists the tools you enabled — nothing more.

tools/list → read_file, run_command, …
3

Request

The model picks a tool and sends typed arguments. The runtime checks key scope, paths, and approval mode.

{ "name": "read_file", "arguments": { "path": "README.md" } }
4

Execute or deny

Allowed calls run and return JSON-RPC results. Denied or unapproved calls return an error — nothing executes.

One runtime, three boundaries.

Managed relay, your own relay, or pure loopback. Execution stays on your machine in every mode.

01 · MANAGEDSolisk hosted

PC access is dangerous when authority is vague. Credentials, scopes, boundaries, and approval mode stay visible.

Read security model
Authenticate every client
Owner and scoped keys travel as bearer credentials. The relay stores salted hashes, never plaintext.
Grant only required tools
Scoped keys constrain categories: file read, shell, input, system, network, screenshots.
Keep execution local
The desktop runtime runs tools. The hosted relay transports authenticated requests — it is not the runtime.
Revoke on demand
Regenerating a device URL kills the old room, drops sessions, and mints a new device identity.

Questions.

Is my PC exposed to the internet?

No. The runtime executes on your machine; the relay only transports authenticated requests. Local-only mode is pure loopback traffic.

What can the AI actually do?

Only what you enable. Scoped keys limit tool categories, allowed paths bound the filesystem, and Ask mode confirms sensitive actions locally first.

Which clients work?

Any MCP client — Claude connectors, ChatGPT, Cursor, local HTTP. One URL plus a bearer key. Setup guide.

Do I need an account?

No. Keys generate on your machine during onboarding and stay there. Devices identify by room code, not identity.

Why does Windows warn about the installer?

The installer is unsigned, so SmartScreen flags it. Install only the official build from GitHub and verify the checksum.

What does it cost?

Core is MIT-licensed; the hosted relay is free during beta. Self-hosting is always available.
